# NOMAD STORIES — Kolsay

Interactive demo v0.1: three guest cabins, date selection, simulated payment, travel journal, conceptual adventure map, team calendar, housekeeping, RU/EN, and day/night modes.

## Website

GitHub Pages setup: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

After deployment the expected address is https://gazizkyrgyzbay-crypto.github.io/nomad-stories/ . The URL is not live until Pages is enabled and deployment succeeds.

## Limitations

This is a prototype, not a real booking service. Payments are simulated; bookings, email addresses and operations records remain in this browser's localStorage and never synchronize with another device. There is no secure account system, staff authorization or backend. Do not enter real customer data. Illustrations are scenic references, not verified property photography; the adventure map is conceptual and not for navigation. Real customer use requires access controls, a shared database, payments, verified location and house details, terms, privacy policy and communications.
