# NOMAD STORIES v0.2 — Development

The existing v0.1 on main continues serving the public GitHub Pages website; this branch provides the new Next.js source.

### Run
```sh
npm install
npm run dev
npm test
```

Open http://localhost:3000. Requires Node.js 22+.

Features: day/night, RU/EN, 3 cabins priced illustratively at ₸45,000/night, unified month range picker, automatic total, demo-only bookings, trip and team demo views. Photos and real amenities are not verified.

**Current branch is not deployed.** GitHub Pages cannot serve this Node server app directly without a separate static export/configuration. Use a suitable Next.js host later. Do not input real guest information.

Security and architecture: see docs folder. No production secrets belong in this public repo.
